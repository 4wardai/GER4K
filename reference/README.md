# GER4K Full-Vision Robot Demo

A standalone HTML/CSS/JS prototype exploring the fuller GER4K mobility experience.

## What's new in this version

- Bus / MRT feeder is now a first-class normal journey option.
- Feeder arrival information is visible and clearly marked **SIMULATED LIVE DATA**.
- Recovery comparison includes a dedicated rail + feeder strategy.
- Station details include pedestrian/interchange walking guidance.
- A movable GER4K robot co-pilot ("Ask G4") can answer prototype questions about:
  - bus / feeder options
  - pedestrian walking
  - fares
  - crowding
  - station/service status
  - route recommendations
  - accessibility considerations
- The robot can be dragged around the screen or docked left/right using buttons.

## How to run

Open `index.html` directly in a modern browser. No build step.

## Suggested demo flow

1. Find routes.
2. Notice the visible **MRT Feeder T508** option.
3. Trigger disruption.
4. Compare rail, low-walking, feeder-supported, and ride-hailing recoveries.
5. Open **Ask G4** and ask:
   - "Is there a bus option?"
   - "How much walking?"
   - "Can I avoid TRX?"
   - "Which route is cheapest?"
   - "I'm travelling with my grandmother."
6. Drag the robot to another part of the screen.
7. Open Pulse → TRX and inspect the pedestrian connection information.
8. Submit a report and receive +5 GER4K Points.

## Honesty

This remains a product-vision prototype. Fares, walking times, feeder arrivals, and some transport attributes are demo/simulated data unless explicitly sourced.
